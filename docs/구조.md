# MyBag 서버 구조

[← README로 돌아가기](../README.md)

## 폴더

```
html/                 웹 루트 (Apache2)
  api/도메인/동작.php   엔드포인트 30개 (auth · trips · itinerary · checklist · weather · profile)
  invite/             초대 링크
  privacy-policy.html, terms.html, withdraw.php
bootstrap/app.php     공통 시작: 오토로드, 환경 변수, DB 연결
config/               DB · CORS · 환경 설정
src/
  Middleware/         인증(JWT), 방 멤버 확인, 방장 확인, 요청 수 제한
  Controller/         요청 검증과 응답
  Service/            규칙과 트랜잭션
  Repository/         SQL
  Client/             외부 API: OpenAI, OpenWeatherMap, Open-Meteo, Kakao, FCM
cron/                 예약 작업 3개
tests/                체크리스트 권한 셀프 체크
```

## 계층

| 계층 | 맡는 일 | 예 |
|---|---|---|
| Middleware | 들어오는 요청을 먼저 거른다 | 방장이 아니면 `TripOwnerMiddleware` 가 403 |
| Controller | 입력 검증, 응답 모양 | `TripController` |
| Service | 규칙과 트랜잭션 | 참여할 때 트랜잭션을 열고 정원 확인 |
| Repository | SQL 만 | `TripRepository` 가 방 행을 `FOR UPDATE` 로 잠가 동시 참여를 한 줄로 세움 |
| Client | 외부 API 호출 | `OpenAiApiClient`, `OpenWeatherApiClient` |

- 엔드포인트 파일 하나가 하나의 API 예요. 파일 안에서 필요한 Repository · Service · Controller 를 직접 조립해요(DI 프레임워크 없음).
- 날씨 API 응답은 `api_cache` 테이블에 캐시해요.

## 예약 작업 (cron)

| 파일 | 하는 일 |
|---|---|
| `departure_notify.php` | 출발 D-7 · D-3 · D-1 푸시 알림, `notification_log` 로 중복 발송 방지 |
| `cleanup_orphans.php` | 방을 만들지 않고 떠나서 남은 업로드 · 분석(파일과 DB 행) 정리 |
| `purge_withdrawn_users.php` | 탈퇴 뒤 유예기간 30일이 지난 계정 삭제 |

## 시험

```sh
php tests/checklist_permission_test.php
```

체크리스트를 체크하고 고칠 수 있는 사람(방장, 담당자, 본인)을 정하는 규칙을 프레임워크 없이 확인해요.
